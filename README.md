## Lancer en local

Ouvre `index.html` via un petit serveur HTTP (les modules ES ne marchent pas toujours en `file://`) :

```bash
# Python
python -m http.server 8080

# ou VS Code / Cursor Live Preview
```

Puis : <http://localhost:8080>
